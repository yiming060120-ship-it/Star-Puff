# 喵汪星云 StarPuff — 8/18 上线 Steam 行动清单

> 目标：2026 年 8 月 18 日前正式上线 Steam。
> 代码（阶段 1-5）已全部完成，剩下的全是**你需要在 Steamworks 后台操作**的事项，以及少量需要你提供的信息。文档按"每天做什么"排好，勾掉一项是一项。

## 一、总览与时间线

代码部分已完成，上线完全取决于后台操作速度和 Steam 审核速度。审核一般 1-3 个工作日，所以**提交审核越早越好**。下面是保守排期：

| 日期 | 你要做的事 | 我这边同步做 |
|---|---|---|
| 8/13（今天） | 提供 AppID、Web API Key；确认图标方案 | 等你给的东西 |
| 8/14 | 完成 Steamworks 后台全部配置（第三节） | 真实 Steam 联调 + 最终打包 + 安全检查 |
| 8/15 | 提交三类审核（Build/商店页/支付） | 用 steamcmd 上传构建到 Steam |
| 8/16-17 | 跟进审核结果，处理驳回项 | 审核通过前做回归验证、内测 |
| 8/18 | 正式 setlive 发布 | 发布后一起做正式环境验收 |

**最大风险提示**：审核需要 1-3 天，8/15 必须提交，否则 18 号赶不上。如果 Steam 后台你完全没注册过，8/13 今晚就要先把账号和缴费搞定。

## 二、8/13（今天）要给我的三样东西

**1. 真实 AppID**
- 如果你之前创建过 Steamworks 应用：登录 partner.steamgames.com，首页"应用与工具"列表里就有，是一个 6 位数字。
- 如果没创建过：后台"应用与工具"→"创建新应用"→填游戏名（喵汪星云 StarPuff）→ 提交后系统分配。这需要先完成账号注册并缴 $100 Steam Direct 提交费（见下条）。

**2. Steam Web API Key**
- 浏览器打开 **https://steamcommunity.com/dev/apikey**，Steam 登录。
- 域名填 `localhost`，点生成，得到一串 32 位字符的 key，发给我。
- 这个 key 只用于沙盒联调，我会存进本机配置文件，绝不打进安装包。

**3. 图标方案二选一**
- 方案 A（不花力气）：我直接从游戏截图生成 `build/icon.ico` 候选图给你选。
- 方案 B：你自己有设计稿，直接给我 256×256 的 PNG。

**如果 Steamworks 账号还没注册**：现在就去 store.steampowered.com 注册开发者账号 → partner.steamgames.com 登录 → 缴 $100 Direct 提交费（正式发售后退还）。这一步不能拖，直接影响能否 8/18 上线。

## 三、8/14 Steamworks 后台配置清单

拿到 AppID 后，在 partner.steamgames.com 后台按顺序完成 6 块配置。每一块我都给了明确参数，照着填即可。

**1. 应用基础信息**
- 游戏名：喵汪星云 StarPuff
- 分类：Windows 独立游戏
- 分级、语言（简体中文）、发行日期填计划日 2026/8/18

**2. 成就登记（8 个）**
- 按 docs/steam/achievements.md 的 8 个成就逐个添加：API 名、显示名、描述、256×256 图标。
- API 名必须与代码里 `src/steam/achievements.ts` 完全一致，否则成就无法解锁。

**3. 云存档**
- 开启 Steam Cloud，文件范围写 `save.json`。

**4. 微交易内购项目（7 个）**
- 到"内购项目"页登记，币种 CNY，ID 与价格必须和 `microtransaction-api/products.json` 完全一致：
  - 100 星尘币×180 = ¥7（首充）
  - 101 星尘币×500 = ¥12
  - 102 星尘币×1000 = ¥22
  - 103 星尘币×2200 = ¥45
  - 104 星尘币×4500 = ¥88
  - 200 VIP 月度 = ¥25
  - 201 VIP 年度 = ¥128
- 不一致会导致交易失败（错误码 8）。

**5. 商店页资料**
- 按 docs/steam/release-checklists/store-page.md 第一节的素材规格上传：胶囊图、Hero 图、宣传图、5 张以上游戏截图。
- 文案用 store-page.md 第二节的初稿。
- 如果截图素材还没准备好，告诉我，我用游戏的自动截图流程批量生成。

**6. 分级问卷**
- 如实填写：无暴力、无性内容、无赌博；微交易按虚拟经济商品如实勾选。

## 四、8/15 提交审核

后台三个入口分别提交，可并行：

1. **Build 审核**：先等我上传构建完成再提交（顺序：上传 → 设为审核分支 → 提交）。
2. **商店页审核**：资料填完即可提交。
3. **支付审核**：微交易项目登记完即可提交。

提交后告诉我，我会盯结果。Steam 审核期间可能提出修改意见，看到驳回消息第一时间截图发我，我来判断怎么改。

## 五、8/16-17 审核期

- 每天早晚各看一次审核状态（后台首页有通知）。
- 若驳回：把驳回说明发我，我给出修改方案，你改后重新提交。
- 若审核通过较快：可以做一轮可选的内测（见 steam-direct-launch.md 第七节），或者直接等 18 号 setlive。

## 六、8/18 正式发布

审核全通过后，在"安装"页把 Build 设为正式版并 setlive，商店页同步发布。发布后我们按这个清单做正式环境验收：

- 从 Steam 商店安装并启动游戏，Shift+Tab 覆盖层正常弹出
- 完成一次真实内购（¥7 档），星尘币到账
- 解锁一个成就，个人资料里能看见
- 云存档跨机恢复正常
- 断网仍可离线游玩
- 到"财务"页核对首笔结算金额与订单一致

全部通过 = 正式上线完成。之后进入日常维护（新版本重新上传 + 审核 + setlive）。

- **提前交付**：如果你 8/13 今晚就能给我 AppID 和 Key，我把联调+打包压缩到 8/14 一整天完成，8/15 早早就提交审核，18 号上线空间会大很多。
