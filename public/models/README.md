# 3D 模型目录说明

此目录存放宠物的 3D 模型文件。**模型文件体积较大（每个 25MB+），已通过 `.gitignore` 忽略，不会提交到 git 仓库**，需要手动放置。

## 需要放置的模型

### 1. 默认宠物模型（必需）

- `pet.glb` —— 默认宠物 3D 模型，主页 3D 模式加载它

### 2. 宠物种类模型（可选，用于升星仪式的模型选择）

放置在 `species/` 子目录下：

```
species/
  species_01.glb
  species_02.glb
  ...
  species_12.glb
```

共 12 个高精宠物模型（对应 `src/data/speciesModels.ts` 里的配置）。

## 注意事项

- 模型格式：`.glb`（推荐）或 `.gltf` + `.bin` + 纹理
- 建议使用 Draco 压缩以减小体积
- 模型文件不会随 git 提交，克隆仓库后需要手动补充
- 游戏在加载不到模型时会有兜底逻辑（2D 像素形象），不会白屏崩溃
